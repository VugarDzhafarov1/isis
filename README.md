\# Инструкция по созданию локального репозитория



Для создания локального репозитория, являющегося копией удалённого репозитория GitHub, необходимо выполнить следующие действия.



1\. Установить Git на компьютер.



2\. Открыть Git Bash в папке, где необходимо разместить локальный репозиторий.



3\. Перейти на страницу необходимого репозитория на GitHub.



4\. Скопировать SSH-адрес репозитория.



Пример SSH-адреса:



git@github.com:USERNAME/REPOSITORY.git



5\. В Git Bash выполнить команду:



git clone git@github.com:USERNAME/REPOSITORY.git



6\. После выполнения команды Git создаст на компьютере папку с названием репозитория и загрузит в неё его содержимое.



7\. Перейти в созданную папку:



cd REPOSITORY



8\. Проверить состояние локального репозитория:



git status



Таким образом, команда git clone позволяет создать локальную копию удалённого репозитория GitHub для дальнейшей работы с файлами, создания изменений, выполнения commit и отправки изменений на GitHub с помощью команды push.
